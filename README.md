# Lumina | Next-Gen Luxury Travel AI & Booking Ecosystem

Lumina is an advanced, high-performance travel planning and concierge web application built as an internship capstone project. It features an immersive glassmorphism UI, scroll-linked dynamic background crossfading, real-time data mocking, and comprehensive itinerary management tools.

## 🚀 Key Features
* **Dynamic Landing Page:** Scroll-linked background crossfading with interactive scatter graphs and modern SaaS architecture.
* **Interactive Trip Planner:** Day-by-day timeline view, tabbed interface, and multi-step requirement engine.
* **Integrated Booking & Validation:** Strict schema validation using Zod and React Hook Form.
* **Interactive Maps & Galleries:** Embedded dark-mode map tiles and curated image grids.
* **Curated Accommodations & Reviews:** Hotel cards with star ratings and a live feedback submission form.
* **Dynamic Budget Calculator:** Real-time cost scaling slider ranging from economy to ultra-luxury options.
* **Wishlist Management:** Instant toggle capability with toast feedback alerts.

## 🛠️ Tech Stack & Architecture
* **Framework:** React 19 + Vite (with Route-based Code Splitting via `React.lazy` & `Suspense`)
* **Styling:** Tailwind CSS (Mobile-First Architecture)
* **Animations:** Framer Motion (3D Tilt Cards, staggered reveals, fluid layout transitions)
* **State Management:** React Context API (Authentication) & TanStack React Query (Server State)
* **API Integration:** Axios & Mock Service Worker (MSW) for realistic network interception
* **Form Validation:** React Hook Form & Zod
* **Notifications:** React Hot Toast
